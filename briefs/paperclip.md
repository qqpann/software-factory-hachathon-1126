# テーマ
小さな町工場でペーパークリップを作って売り、工場を大きくしていくインクリメンタル（クリッカー）ゲーム。
最初は手でクリップを1本ずつ曲げて作り、売上で針金を買い足し、自動で作る機械を増やしていく。
既存の有名作品の再現ではなく、名前・文章・進行はすべてオリジナルにする。

# 意思
- 主な操作はマウスのクリック（画面上の大きなボタン）。同じ操作をキーボードでもできるとなお良い。
- 最初の10秒で「ボタンを押すとクリップが1本できる」ことが分かる。
- 作る → 売る → 針金を買う → 機械を買う、の流れが画面だけで分かる。今買えるものは目立たせ、買えないものは理由（お金が足りない等）が見える。
- 数字が増えていく気持ちよさがあり、機械を買うと生産ペースがはっきり上がる。
- 針金が切れると生産が止まる、など小さな判断がある。
- 合計 1,000 本を作ればクリア。上手に投資すれば、ゲーム内時間で3〜4分ほどでクリアできる。放置だけではクリアできない。
- 負けはない。クリア画面で記録（かかった時間）を表示し、Spaceでもう一度遊べる。
