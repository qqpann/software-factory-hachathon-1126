## 操作方法
ゲームはあなた専用のブラウザで開いています。ゲーム内の時間は止まっていて、あなたが行動したときだけ進みます。考える時間は気にしなくてよいです。

次のコマンドだけを使って遊んでください（Bashで実行）。

```
node {{play}} look                      # 今の画面を見る（時間は進まない）
node {{play}} press Space               # キーを1回押す（約0.15秒進む）
node {{play}} hold ArrowLeft 600        # キーを押し続ける（ミリ秒、最大3000）
node {{play}} hold ArrowUp+ArrowRight 400  # 同時押し
node {{play}} click 480 360             # クリック（画面は960×720）
node {{play}} wait 1000                 # 何もせず待つ
node {{play}} restart                   # 最初から開き直す
```

キー名は Playwright の形式です（ArrowLeft, Space, Enter, KeyZ など）。

各コマンドは JSON を返します。`screenshot` に書かれた画像を **Read ツールで必ず見て**、次の行動を決めてください。`game` は画面外の補助情報（state と score）です。行動回数は合計 {{maxActions}} 回までです。

## 進め方
1. まず `look` して画面を見て、何をすればよいか**画面から**読み取ってください。分かりにくければそれ自体が評価対象です。
2. 本気で勝とうとして遊んでください。負けたら何が原因だったか考え、やり直してもう一度挑戦してください。
3. 操作が効かない、画面が崩れる、理不尽に負ける、何が起きているか分からない、などは必ず記録してください。証拠として screenshot のパスを添えます。
